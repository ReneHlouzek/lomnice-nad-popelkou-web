# Lomnice nad Popelkou – nový web

Základní statická webová prezentace města připravená pro GitHub Pages.

## Soubory
- `index.html` – úvodní stránka
- `style.css` – vzhled a responzivní rozložení
- `main.js` – navigace a drobné interakce
- `assets/images/` – fotografie úvodní stránky (složku vytvoříš při prvním nahrání fotografií)

## Fotografie pro úvodní stránku
Nahraj fotografie do složky `assets/images/` s těmito názvy:

| Soubor | Umístění na webu | Doporučené rozměry |
|---|---|---|
| `uvodni-foto.jpg` | Velká úvodní fotografie přes šířku obrazovky | 2000 × 1100 px |
| `mesto-detail-1.jpg` | Hlavní fotografie města | 1200 × 900 px |
| `mesto-detail-2.jpg` | Krajina | 900 × 700 px |
| `mesto-detail-3.jpg` | Život ve městě | 900 × 700 px |
| `navstevnik.jpg` | Část Pro návštěvníky | 1400 × 800 px |

V GitHubu otevři repozitář, zvol **Add file → Upload files**, přetáhni fotografie a do pole pro cestu/název zadej `assets/images/nazev-souboru.jpg`. GitHub tím vytvoří potřebnou složku. Poté potvrď **Commit changes**.

## GitHub Pages
V repozitáři otevři **Settings → Pages** a nastav **Deploy from a branch**, větev `main` a složku `/ (root)`. Potvrď **Save**.

Web pak bude dostupný na:
https://reneh louzek.github.io/lomnice-nad-popelkou-web/

## Poznámka
Stránka je zatím úvodní vizuální kostra. Odkazy na další sekce a obsah postupně napojíme na skutečné stránky a ověřené informace města.
